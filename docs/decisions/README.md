# Architectural Decision Records (ADRs)

We use Architectural Decision Records to capture important architectural decisions along with their context and consequences. We store these decisions in this directory.

## Numbering

ADRs are numbered sequentially with a 4-digit prefix (e.g., `0001-record-architecture-decisions.md`).

## Template

Use `0000-adr-template.md` as a starting point for new ADRs.

## Statuses

- **Proposed**: Under review.
- **Accepted**: Agreed upon and being implemented.
- **Deprecated**: No longer active or relevant.
- **Superseded**: Replaced by a newer ADR (link to it).
